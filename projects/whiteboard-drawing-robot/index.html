Whiteboard Drawing Robot

Robot Mechanics project combining mechanical design, closed-loop kinematics, image processing, motion planning, and Raspberry Pi motor control.

Mechanism

The project geometry uses a 48 × 60 in whiteboard, 20 in primary link, 20 in forearm, and a separate 20 in secondary connecting rod. The interactive view below is a kinematic visualization built directly from those project dimensions; the pulley geometry comes from the STEP files included with the CAD assembly.

Drawing Pipeline

Input Imageload and clean the source image
Vectorizeconvert image features into strokes
Fit Pathsscale and fit strokes inside the reachable board area
Kinematicsmap marker positions through the closed-loop arm geometry
Executesend planned motion to the Raspberry Pi hardware

Software

The Python project includes image vectorization, B-spline path generation, exact closed-loop linkage calculations, motor-step planning, G-code export, a desktop preview application, Raspberry Pi execution, and verification tests.
