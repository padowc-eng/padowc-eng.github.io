Whiteboard Drawing Robot

Robot Mechanics project combining mechanical design, kinematics, image processing, motion planning, and Raspberry Pi motor control.

Overview

The system converts an input image into drawing paths for a planar whiteboard arm. The software handles image cleanup and vectorization, closed-loop linkage kinematics, B-spline path fitting, motion planning, and execution on a Raspberry Pi.

System

The design uses a two-link drawing arm with stepper-motor reductions and a servo-actuated marker lift. A desktop application provides path preview, hardware execution, and G-code export.

Source Code

Clean project source containing the desktop application, linkage geometry, vectorization, path generation, motion planning, Raspberry Pi worker, and verification tests.
